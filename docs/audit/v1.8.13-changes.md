**直し方**

1. **語の範囲で測る**。`matcher` の一致位置から Range を作り、その矩形で判定する（`visibleHits` / `isPaintedRange`）。記録の使用可能性も、記録した語の範囲で見る
2. **逃げてよいのは `overflow` だけ**。`clip` と `clip-path` は要素と子孫の描画そのものを制限するので、包含ブロックの例外を適用しない（`ownClips` が3つに分けて返す）
3. **形そのものと交差判定する**。円・楕円は解析的に、`inset(... round R)` は角丸として。`transform` は平行移動だけなら辺の削り込みを保つ。root（`body` / `html`）の `overflow` だけを特別扱いし、形と描画効果は無視しない

直したあと、上の9件すべてで**画素と印が一致**します。

## 残る限界

- 名札を**全部**消された複製は、見えない Tab の停止点として残る（ページの持ち物と区別できないため触れない）
- `polygon()` / `path()` / `shape()` / `calc()` は解かない（可視へ倒す）
- ページが `position` / `z-index` / `pointer-events` を自分で指定していない同名要素では、その3つを初期値へ戻す
